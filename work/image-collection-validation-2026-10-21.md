# v1.9.0 图片采集验证记录

日期：2026-10-21；基线 v1.8.3。实现方案见 image-collection-plan-2026-10-21.md。

## 交付契约

在数据抓取或定时任务的“采集范围与恢复设置”中选择“仅图片（下载图片文件）”。程序自动检查关键词命中主帖及其评论的图片，不区分纯图和文字配图；评论开关自动开启，资源屏蔽自动关闭。主帖数量目标与图片数量分别统计。

图片缓存位于用户数据目录 images/；手动“保存图片 ZIP 与来源清单”使用下载目录（默认用户 Downloads）；定时任务结束后按任务名＋完成月日导出 ZIP 到任务保存目录。包内 images/ 存放去重原文件，manifest.csv/json 保留每个来源，summary.json 记录快照状态。

“只补图片”处理已发现地址，不进行搜索或重新遍历评论。若评论未检查完整，需“只补评论”或“继续补抓”。图片下载和评论完整性分别判断；平台拒绝访问、外链不支持、容量限制均不误报成功。

## 平台结构与功能验证

- 真实 Chromium 执行 X 提取脚本：主帖图、无文字图片评论、文字配图评论均提取，头像/视频封面/已识别引用帖排除。
- Reddit 结构样本覆盖图集、GIF、评论 metadata 和 Markdown 图片、多级评论根帖关联；不将视频缩略图当主图。
- JPEG、PNG、WebP、动画 GIF 下载字节原样保留；格式/尺寸/像素解码检查，截断 JPEG、HTML 和超限文件拒绝。
- 原图 403 后回退、429、503、假图、超大响应、无 Content-Length、恶意重定向、超时、中途取消、缓存损坏/丢失、磁盘导出状态和容量上限均有回归。
- API 批量搜索 → 后台线程 → 图片持久化 → ZIP → 只补图片闭环，定时任务自动 ZIP 和无 Cookie 的已发现图片补下载通过。
- 切换定时任务内容模式后，历史去重不混用；没有正文的持久化/交付检查通过。
- 图片清单按 SHA256 关联文件，可用于审核接入；未自动上传或调用外部审核。

## Windows 发布压测追加修复

首次发布 CI 的 HTTP 并发测试发现采集历史接口返回 500；原测试未输出服务端堆栈。补充诊断后，普通冷启动 30 轮未重现；强化为 20 线程同时打开新数据库后，在 Windows 首轮直接复现 `Store.__init__` 的 `PRAGMA journal_mode=WAL` 抛出 `sqlite3.OperationalError: database is locked`（Actions 39583689898）。

修复为进程内串行化数据库模式和表结构初始化，连接配置错误也确保关闭连接；不串行化后续正常读写。新增冷启动测试每轮覆盖 10 个独立新库；原 HTTP 压测保留失败堆栈输出。修复后本地相关 37 项及完整 290 项通过。

Windows 修复后 30 轮全部通过（Actions 39584110950），共 60 项测试、300 个独立新库、每库 20 线程同时初始化、9000 次真实 HTTP 请求。日志 /private/tmp/v190-windows-fixed.log。临时诊断流水线已移除，回归场景保留在正式发布测试中。

后续完整 Windows 回归 290 项通过；图片界面测试发现脚本未声明页面文本编码，已显式使用 UTF-8，避免 Windows 默认 cp1252 解码失败。该处为测试加载页面的问题，生产页面服务不使用这一读取路径。

此数据库竞争不是用户 Win11 白屏的已确认根因。

## 压力场景规模

- 真实本地 HTTP：3 个独立线程/事件循环同时运行，总计 60 次图片下载，实测并发连接最高 2；截断响应两次后明确失败，临时文件清理，SQLite integrity_check=ok。
- 600 主帖＋600 评论图片，共 1200 图片来源，重复发现不增加记录；20 并发、300 次轻量汇总读取；同内容仅 1 个图片文件，但保留全部 1200 条来源。
- 同时导出两个 ZIP，不覆盖；清单 1200 条、其中评论来源 600 条，ZIP 校验与图片字节匹配；恢复已成功图片不重新请求。
- 取消后重新打开数据库补下载；重试不会因为后续关键词重复触发而无限循环。

## 验证边界

测试使用临时数据、平台结构样本、模拟响应、真实本地 HTTP 和 Chromium。没有登录真实 X/Reddit 账号开展在线压力测试，没有用户 Win11/WebView2 实机验证。只能验证本次实现的处理及恢复行为，不能保证平台永不更改结构、所有评论或原图均可访问。既有跨日任务尚需对应日志诊断，不宣称此次修复了它。

原生 CDN 支持范围、20 MiB/4000万像素/45秒/10000地址/2 GiB 等限制见方案及更新日志；达到限制会产生明确未完成状态。压力测试图片为小型有效样本，容量边界用受控测试验证，不等同于 2 GiB 真实素材长期运行。
